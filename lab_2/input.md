# Лабораторная работа 2 Алгоритмы сортировки
1. Вы разрабатываете маркетплейс, у вас множество товаров  в базе. Подготовительным этапом вашей лабораторной работы будет генерация товаров. Вам необходимо сгенерировать 1 миллион товаров (структур) рандомно и добавить их в список
 
"id" - это артикул товара, "name" - его название
# Пример заполнения списка товаров ниже. Данные обязательно должны быть НЕ отсортированны
sorted_products = [
    {"id": 120, "name": "Ноутбук"},
    {"id": 101, "name": "Кабель"},
    {"id": 110, "name": "Монитор"},
    {"id": 105, "name": "Мышь"}
]
 
2. Теперь нужно проверить алгоритмы сортировки на вашем списке. Выберите 2 алгоритма из простых сортировок, один алгоритм из быстрых сортировок
 
3. Замерьте время (time.perf_counter()) выполнения каждого алгоритма для каждой сортировки. Постройте итоговую таблицу результатов. Сделайте выводы
 
4. Реализуйте решение задачи:
 
Контекст: На сервер вашего маркетплейса за секунду прилетело 10 000 запросов. Нужно быстро построить отчет: сгруппировать их по результату ответа и упорядочить по IP-адресам, чтобы выявить DDoS-атаку.
 
Реализация Counting Sort: Сортировка по HTTP-статусам
Диапазон значений строго ограничен стандартами (от 100 до 599). За один проход вы раскидывают миллионы логов по корзинам ответов (200 OK, 404 Not Found, 500 Error).
 
Реализация Radix Sort: Сортировка по IP-адресам (например, IPv4)
IP-адрес состоит из 4-х байт (например, 192.168.1.1). Вы реализуете поразрядную сортировку, где один разряд — это один байт (значение от 0 до 255).
