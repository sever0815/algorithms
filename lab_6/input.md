Учитывая root двоичное дерево, верните длину диаметра дерева.

Диаметр двоичного дерева — это длина наибольшего пути между любыми двумя узлами дерева. Этот путь может проходить через корневой узел, а может и не проходить через него

Длина пути между двумя узлами представлена числом ребер между ними.

Обязательно реализовать бинарное дерево как структуру данных.

Пример 1:

Ввод: корень = [1,2,3,4,5]

Вывод: 3

Пояснение: 3 — длина пути [4,2,1,3] или [5,2,1,3].

Пример 2:

Вход: корень = [1,2]

Выход: 1 — длина пути [1,2]
 
Изображение не относится к примерам 1 и 2, оно нужно только для демонстрации диаметра

Учитывая корень двоичного дерева с уникальными значениями и значениями двух различных узлов дерева x и y, вернуть true, являются ли узлы, соответствующие значениям x и y в дереве являются кузенами, или false, если нет.

Два узла бинарного дерева являются кузенами, если они имеют одинаковую глубину и разных родителей.

Обратите внимание, что в двоичном дереве корневой узел находится на глубине 0, а дочерние узлы каждого k узла глубины находятся на глубине k + 1.

Обязательно реализовать бинарное дерево как структуру данных.

Пример 1:

Вход: корень = [1,2,3,4], x = 4, y = 3

Выход: false

Пример 2:

Вход: корень = [1,2,3,null,4,null,5], x = 5, y = 4

Выход: true

Изображения для примеров 1 и 2

![[D.png]] 


Даны корни двух двоичных деревьев root и subRoot. Вернуть true, существует ли поддерево root с той же структурой и значениями узлов как у subRoot, и false в противном случае.

Поддерево бинарного дерева — это дерево, состоящее из узла tree и всех его потомков. Дерево также можно рассматривать как поддерево самого себя.

Обязательно реализовать бинарное дерево как структуру данных.

Пример 1:

Ввод: root = [3,4,5,1,2], subRoot = [4,1,2]

Вывод: true

Пример 2:

Ввод: root = [3,4,5,1,2,null,null,null,null,0], subRoot = [4,1,2]

Вывод: false
