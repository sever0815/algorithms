# Описание основных алгоритмов поиска:

### 1. Линейный поиск (Linear Search)
Это самый простой метод поиска. Алгоритм последовательно просматривает каждый элемент в списке, начиная с первого, и сравнивает его с искомым значением.
*   **Принцип:** Проход по всему списку «элемент за элементом».
*   **Сложность:** $O(n)$, где $n$ — количество элементов. В худшем случае (если искомый элемент последний или отсутствует) придется проверить все элементы.
*   **Особенность:** Не требует предварительной сортировки данных.

### 2. Бинарный поиск (Binary Search)
Алгоритм работает только с **отсортированными** данными. Он постоянно делит область поиска пополам.
*   **Принцип:** Сравнивает искомое значение со средним элементом списка. Если искомое число меньше среднего, поиск продолжается в левой половине, если больше — в правой. Шаг повторяется до тех пор, пока элемент не будет найден или диапазон не станет пустым.
*   **Сложность:** $O(\log n)$. Это делает его очень эффективным для больших массивов данных.
*   **Особенность:** Требует обязательной сортировки списка перед началом поиска.

### 3. Экспоненциальный поиск (Exponential Search)
Также используется для **отсортированных** массивов. Он эффективно находит «диапазон» поиска, а затем применяет бинарный поиск.
*   **Принцип:** Сначала ищется диапазон, в котором может находиться элемент, увеличивая индекс проверки экспоненциально (1, 2, 4, 8, 16...). Как только значение по текущему индексу становится больше искомого, границы найдены, и внутри этого диапазона запускается классический бинарный поиск.
*   **Сложность:** $O(\log i)$, где $i$ — позиция искомого элемента. Часто бывает быстрее бинарного поиска, если искомый элемент находится ближе к началу массива.
*   **Особенность:** Отлично подходит для массивов неограниченного размера или очень больших отсортированных данных.

### 4. Интерполяционный поиск (Interpolation Search)
Более продвинутый алгоритм для **отсортированных** массивов, который работает как «поиск по справочнику» или «поиск слова в словаре» (человек не открывает книгу посередине, а пытается угадать страницу по первой букве слова).
*   **Принцип:** Вместо деления массива строго пополам, алгоритм вычисляет примерную позицию элемента на основе разницы между искомым значением и значениями на краях диапазона.
*   **Сложность:** $O(\log(\log n))$ при равномерном распределении данных. В худшем случае может деградировать до $O(n)$.
*   **Особенность:** Работает невероятно быстро, если данные равномерно распределены, но сильно теряет в эффективности, если данные «сгруппированы» или распределены хаотично.
